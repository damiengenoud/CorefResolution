# CorefResolution
Repository of the Coreference Resolution for Story Visualization Project.

## Instructions
- First run `sh requirements.sh` to download the necessary data and libraries
- In the Jupyter Notebook file `coref_model.ipynb`, you can run the training cell (the first cell) to train a model yourself, or you can run the second cell to evaluate a pre-trained model.
- You can tweak some parameters in the file `config.py` to train different models.
